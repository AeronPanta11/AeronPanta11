### 💫 About Me

I'm a Computer Engineering graduate building reliable, production-grade AI systems — from research and experimentation to containerised API deployment. My focus areas are **NLP, Computer Vision, and Retrieval-Augmented Generation**, and I've worked across the full ML lifecycle, including a production internship at Sleepfix.ai.

**🔭 Currently building:**
- **Auto Merge** — an AI-powered plugin that resolves GitHub merge conflicts using a fine-tuned CodeT5 model combined with the Diff3 algorithm for complex, nested conflict scenarios.
- **Resume Screener** — an LLM-based system that scores candidate resumes against a job description, helping recruiters shortlist faster with structured, auditable scoring.

**🌱 I'm into:** LLM fine-tuning, hybrid retrieval systems, and turning ML prototypes into dependable, deployed services.
